## ⚙️ Como rodar os projetos:

Você pode rodar esses códigos de duas formas:

### Pelo Terminal:
1. Tenha o Python instalado no seu computador.
2. Abra o terminal (ou CMD) na pasta do arquivo.
3. Digite: `python nome_do_arquivo.py`

### Pelo VS Code (Recomendado):
1. Abra a pasta do projeto no VS Code.
2. Certifique-se de que a extensão oficial do **Python** está instalada.
3. Clique no botão de **Play** (triângulo no canto superior direito) ou aperte `F5`.
